# Notice

Skill Safety Bench contains runner scripts, benchmark case definitions, local task environments, skills, and bundled artifacts used for safety evaluation.

Before public release, verify attribution and provenance records for:

- upstream benchmark/task sources represented in benign task content
- copied or adapted skill folders and helper scripts
- bundled archives, PDFs, PPTX files, CSV files, MP4 files, and other media/data assets
- local task artifacts whose provenance should be documented

The repository is intended for controlled research evaluation. It includes adversarial examples that simulate unsafe system behavior and should not be run with production credentials or sensitive local data.
